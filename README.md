# CAREN's Auction 🚗

## Deskripsi
CAREN's Auction merupakan aplikasi pelelangan berbasis web yang dikembangkan menggunakan HTML, CSS, PHP, dan MySQL. Aplikasi ini bertujuan mempermudah pengelolaan barang lelang serta proses penawaran dan transaksi secara digital.

## Fitur
- Login Admin dan User.
- Menampilkan dan mencari barang lelang.
- Melihat detail barang dan riwayat penawaran.
- Melakukan penawaran harga (Bid).
- Mengajukan barang untuk dilelang.
- Verifikasi pengajuan barang oleh Admin.
- Mengelola data barang dan pengguna.
- Mengakhiri proses lelang dan pembayaran.

## Teknologi
- HTML
- CSS
- PHP
- MySQL

## Instalasi
1. Download atau clone repository.
2. Simpan folder proyek di `htdocs`.
3. Jalankan Apache dan MySQL melalui XAMPP.
4. Buat database bernama `dbauction`.
5. Import file `dbauction.sql` melalui phpMyAdmin.
6. Sesuaikan konfigurasi database di `backend/kelas-auction.php`.
7. Jalankan melalui browser menggunakan `localhost`.
